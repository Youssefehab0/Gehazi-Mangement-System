# Gehazi | Gehazi System

An Arabic web project designed to present services, facilities, and a residential/commercial area in a simple and fast way. It focuses on a clear Arabic user experience, with key pages such as the homepage, news, registration, bookings, and complaints.

## Project Description

"Gehazi" is a website system/interface designed to:

- Display available services in the area
- Provide a quick and easy way to book a queue number
- Offer a news page for local updates and announcements
- Receive complaints or enable communication with the management
- Support an Arabic browsing experience that is responsive across different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript (for basic interactions and simple navigation)
- Font Awesome Icons

## How to Run

1. Download or clone the project locally.
2. Open the main project folder.
3. Open [index.html](index.html) in your browser.

You can also open any page in the [pages](pages) folder directly if needed.
